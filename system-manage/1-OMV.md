# 2. 用户管理
root: 拥有最高权限的用户，为所欲为，甚至删除整个系统，慎用
admin：omv-web界面管理用户，也有非常高的权限，管理系统推荐使用此账户，而非root
openclaw：ai助手的账户，工作的主账户

# 5. smb局域网共享文件
