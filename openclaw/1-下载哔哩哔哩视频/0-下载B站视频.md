# 安装skill
```sh
openclaw@openclaw:~$ npx clawhub search "video-downloader"

video-downloader  Video Downloader  (4.193)
video-transcript-downloader  Video Transcript Downloader  (3.251)
.....
video-downloader-skill  支持从 YouTube、Bilibili、抖音及所有 yt-dlp 兼容平台下载视频，可自动选择最佳分辨率、合并音视频并清理文件名  (2.004)
twitter-video-downloader  推特视频下载器  (1.880)
bili-video-downloader  B站视频下载器  (1.847)

openclaw@openclaw:~$ npx clawhub install "video-downloader-skill"

```
# 安装skill需要的依赖（可以省略）
```sh
sudo apt update
sudo apt install ffmpeg yt-dlp
```
