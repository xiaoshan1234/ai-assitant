# OpenClaw 接入钉钉

本文介绍如何将 **钉钉机器人** 接入 OpenClaw，在钉钉中与 AI 助手对话。钉钉使用 **Stream 模式（长连接）**，无需公网 IP 与回调地址，部署在 NAT 或内网环境也可使用。

---

## 前置条件

- 拥有**钉钉**账号，且具备在组织内**创建应用/机器人**的权限（通常需管理员）。
- OpenClaw 已安装并已配置模型，网关可正常启动（`openclaw gateway status` 为 running）。

---

## 一、在钉钉开放平台创建机器人应用

1. 打开 [钉钉开放平台](https://open-dev.dingtalk.com/)，使用钉钉扫码登录。
2. 进入 **应用开发** → **企业内部开发**（或对应入口），点击 **创建应用**。
3. 选择应用类型为 **机器人**。
4. 填写应用名称、描述等必填项，完成创建。
5. 在应用详情页进入 **凭证与基础信息**，保存：
   - **Client ID**（即 AppKey，格式如 `dingxxxxxxxxxx`）
   - **Client Secret**（AppSecret，仅展示一次，务必保存）
6. 在 **版本管理与发布** 中创建版本、填写说明并**发布应用**（不能保持草稿状态，否则机器人不可用）。

钉钉机器人使用 **Stream 模式** 时无需配置回调 URL，也无需公网 IP。

---

## 二、安装钉钉渠道插件

在终端执行：

```bash
openclaw plugins install @soimy/dingtalk
```

若国内网络较慢或报错，可指定镜像后安装：

```bash
NPM_CONFIG_REGISTRY=https://registry.npmmirror.com openclaw plugins install @soimy/dingtalk
```

验证：`openclaw plugins list` 中应能看到钉钉相关插件（如 `@soimy/dingtalk` 或 dingtalk）。

若你使用的 OpenClaw 版本要求显式允许插件，需在配置中加入插件白名单（见下文「方式二」）。

---

## 三、在 OpenClaw 中配置钉钉渠道

### 方式一：交互式添加（推荐）

1. 运行：
   ```bash
   openclaw channels add
   ```
2. 在 channel 列表中选择 **DingTalk**（或 钉钉）。
3. 按提示输入 **Client ID**（AppKey）和 **Client Secret**（AppSecret），完成配置。

### 方式二：编辑配置文件

编辑 OpenClaw 主配置：

- **Windows**：`%USERPROFILE%\.openclaw\openclaw.json`
- **Linux / macOS**：`~/.openclaw\openclaw.json`

在 `channels` 中增加 `dingtalk` 配置：

```json
{
  "channels": {
    "dingtalk": {
      "enabled": true,
      "clientId": "你的ClientID即AppKey",
      "clientSecret": "你的ClientSecret"
    }
  }
}
```

若需按环境变量注入密钥，可使用（具体以当前插件文档为准）：

```json
{
  "channels": {
    "dingtalk": {
      "enabled": true,
      "clientId": "${DINGTALK_CLIENT_ID}",
      "clientSecret": "${DINGTALK_CLIENT_SECRET}"
    }
  }
}
```

若你的环境要求**插件白名单**，在配置中增加（或合并）：

```json
{
  "plugins": {
    "enabled": true,
    "allow": ["dingtalk"]
  }
}
```

### 方式三：通过管理页面

1. 打开 OpenClaw 管理页面（默认 `http://127.0.0.1:18789`）。  
   若 OpenClaw 在远程服务器，可先建立 SSH 隧道：`ssh -L 18789:127.0.0.1:18789 用户@服务器IP`
2. 左侧进入 **Channels**，找到 **DingTalk**（钉钉），点击配置。
3. 填入 **Client ID** 和 **Client Secret**，保存。

---

## 四、启动或重启网关

```bash
openclaw gateway restart
```

或若未安装为服务，可前台启动：

```bash
openclaw gateway --port 18789 --verbose
```

确认状态：

```bash
openclaw gateway status
```

---

## 五、验证是否成功

1. 在 **钉钉** 中搜索你刚创建并已发布的机器人（应用名称或机器人名称）。
2. 打开与机器人的会话，发送一条消息（如「你好」）。
3. 若机器人能正常回复，说明接入成功。

可配合 `openclaw logs --follow` 查看是否有钉钉相关连接或报错信息。

## 六、常用命令

| 命令 | 说明 |
|------|------|
| `openclaw gateway status` | 查看网关状态 |
| `openclaw gateway restart` | 重启网关 |
| `openclaw logs --follow` | 查看实时日志 |

---

## 七、常见问题

| 现象 | 处理建议 |
|------|----------|
| 机器人收不到消息 / 无回复 | ① 确认应用已**发布**（非草稿）；② 核对 Client ID、Client Secret 是否与开放平台一致；③ 确认网关在运行（`openclaw gateway status`）；④ 查看 `openclaw logs --follow` 中钉钉相关报错。 |
| 需要配置回调地址吗？ | 不需要。钉钉使用 Stream 长连接模式，无需公网 IP 和回调 URL。 |
| 安装插件报 npm 错误 | 使用 `NPM_CONFIG_REGISTRY=https://registry.npmmirror.com` 前缀重新执行安装命令。 |
| 插件未加载或渠道不显示 | 检查 `openclaw.json` 中是否配置了 `plugins.allow` 并包含 `"dingtalk"`，配置后执行 `openclaw gateway restart`。 |
