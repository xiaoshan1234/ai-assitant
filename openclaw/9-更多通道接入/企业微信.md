# OpenClaw 接入企业微信

本文介绍如何将 **企业微信智能机器人** 接入 OpenClaw，在企业微信中与 AI 助手对话。推荐使用 **长连接模式**，无需公网 IP 与回调地址；若使用 **URL 回调模式**，则需服务器具备公网可访问的 IP 或域名。

---

## 前置条件

- 拥有**企业微信**账号，且具备在企业内创建智能机器人的权限（通常需管理员）。
- OpenClaw 已安装并已配置模型，网关可正常启动（`openclaw gateway status` 为 running）。

---

## 方式一：长连接模式（推荐，无需公网）

长连接模式下，机器人通过 WebSocket 主动连接企业微信服务器，**无需配置公网 IP、域名或回调 URL**，适合本地或内网部署。

### 一、在企业微信创建长连接机器人

1. 打开企业微信 **客户端**，进入 **工作台**。
2. 找到 **智能机器人** → **创建机器人**，选择 **API 模式** 创建。
3. 选择 **长连接** 方式，获取并保存：
   - **Bot ID**
   - **Secret**

官方说明页：[企业微信支持接入 OpenClaw](https://work.weixin.qq.com/nl/index/openclaw)

### 二、安装企业微信插件

在终端执行：

```bash
openclaw plugins install @wecom/wecom-openclaw-plugin
```

验证：`openclaw plugins list` 中应能看到该插件。

### 三、启动网关并添加渠道

1. 启动或确认网关在运行：
   ```bash
   openclaw gateway start
   ```
   若已安装为系统服务，可用 `openclaw gateway status` 查看状态。

2. 添加企业微信渠道：
   ```bash
   openclaw channels add
   ```
   - 在 **Select channel** 步骤选择 **企业微信**（或 WeCom）。
   - 按提示输入 **Bot ID** 和 **Secret**。
   - 配对方式选择 **Pairing**，按提示完成并 **finish**。

### 四、完成配对

1. 回到企业微信 **机器人创建/配置页**，点击 **保存并创建**（或保存）。
2. 在企业微信中**给该机器人发一条消息**（如「你好」）。
3. 机器人会回复一条包含 **配置密钥** 的消息，复制消息中最后一行的密钥。
4. 在终端中按提示**粘贴该配置密钥**并回车，完成配对。
5. 配对成功后，即可在企业微信中与机器人正常对话。

### 五、重启网关（若修改过配置）

```bash
openclaw gateway restart
```

## 方式二：URL 回调模式（需公网 IP 或域名）

若你无法使用长连接，或使用的是依赖 URL 回调的企微插件，可按以下方式配置。**已认证企业**须使用已备案且主体一致的域名；**未认证企业**可先用服务器公网 IP 测试。

### 一、在企业微信创建 API 模式机器人

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)，进入 **安全与管理** → **管理工具** → **创建机器人**。
2. 选择 **API 模式创建**。
3. 填写：
   - **名称**：如「OpenClaw 助手」
   - **简介**：机器人描述
   - **可见范围**：选择可使用该机器人的部门或成员
   - **URL**：`http://你的公网IP或域名:18789/wecom`（示例：`http://12.12.12.12:18789/wecom`）
4. 点击 **随机获取**，生成 **Token** 和 **EncodingAESKey**，妥善保存。
5. **先不要点创建**，需先在 OpenClaw 中完成渠道配置并启动网关，再回到此页点击创建。

### 二、在 OpenClaw 中配置企业微信

**通过向导**：运行 `openclaw onboard`，在 Select channel 步骤选择 **WeCom (plugin)**，按提示输入 Token、EncodingAESKey，Webhook 路径保持默认 `/wecom`。

**通过管理页面**：打开 `http://127.0.0.1:18789`（远程服务器可用 SSH 隧道 `ssh -L 18789:127.0.0.1:18789 用户@服务器IP`），进入 **Channels** → 找到 **WeCom** → 填入 Token 与 EncodingAESKey → 保存。

**通过配置文件**：编辑 `~/.openclaw/openclaw.json`（Windows：`%USERPROFILE%\.openclaw\openclaw.json`），在 `channels` 中增加或修改 wecom 配置（具体字段名以所用插件文档为准，通常包含 token、encodingAesKey、webhook 路径等）。

### 三、启动网关并放行端口

```bash
openclaw gateway --port 18789 --verbose
```

确保服务器 **防火墙已放行 18789 端口**，且该端口对公网可访问。

### 四、完成企业微信侧创建

回到企业微信机器人创建页，点击 **创建**。创建成功后扫码添加机器人，即可在聊天中与机器人对话（回调模式一般无需额外配对步骤）。

## 常用命令

| 命令 | 说明 |
|------|------|
| `openclaw gateway status` | 查看网关状态 |
| `openclaw gateway restart` | 重启网关 |
| `openclaw logs --follow` | 查看实时日志 |

---

## 常见问题

| 现象 | 处理建议 |
|------|----------|
| 长连接：配对失败或收不到配置密钥 | 确认 Bot ID、Secret 无误；确认已在企微侧保存机器人并先发一条消息；查看 `openclaw logs --follow` 中是否有报错。 |
| 回调模式：URL 验证失败 | 检查 URL 是否为 `http://IP或域名:18789/wecom`、Token 与 EncodingAESKey 是否与企微一致、18789 端口是否对公网开放、网关是否已启动。 |
| 已认证企业必须用域名 | 是的，已认证企业配置的 URL 须为已备案且主体与认证企业一致的域名。 |
