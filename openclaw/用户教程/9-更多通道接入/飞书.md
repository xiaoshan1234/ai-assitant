# OpenClaw 接入飞书

飞书渠道支持机器人私聊和群聊，通过 WebSocket 长连接接收消息，无需公网域名。

## 一、安装飞书插件

在终端执行：

```bash
openclaw plugins install @openclaw/feishu
```

验证安装：`openclaw plugins list` 中应能看到 `@openclaw/feishu`。

---

## 二、在飞书开放平台创建应用

### 1. 打开开放平台

- **国内飞书**：访问 [飞书开放平台](https://open.feishu.cn/app)，使用飞书账号登录。
- **Lark 国际版**：访问 [Lark 开放平台](https://open.larksuite.com/app)，配置时需在 OpenClaw 中设置 `domain: "lark"`。

### 2. 创建企业自建应用

1. 点击「创建企业自建应用」；
2. 选择应用图标，填写应用名称和描述；
3. 创建完成后进入应用管理。

### 3. 获取应用凭证

在 **凭证与基础信息** 页面复制并妥善保存：

- **App ID**（格式如 `cli_xxx`）
- **App Secret**（仅展示一次，务必保存）

### 4. 配置应用权限

在 **权限管理** 页面，点击 **批量导入**，粘贴以下 JSON 并导入：

```json
{
  "scopes": {
    "tenant": [
      "aily:file:read",
      "aily:file:write",
      "application:application.app_message_stats.overview:readonly",
      "application:application:self_manage",
      "application:bot.menu:write",
      "cardkit:card:write",
      "contact:user.employee_id:readonly",
      "contact:contact.base:readonly",
      "corehr:file:download",
      "docs:document.content:read",
      "event:ip_list",
      "im:chat",
      "im:chat.access_event.bot_p2p_chat:read",
      "im:chat.members:bot_access",
      "im:message",
      "im:message.group_at_msg:readonly",
      "im:message.group_msg",
      "im:message.p2p_msg:readonly",
      "im:message:readonly",
      "im:message:send_as_bot",
      "im:resource",
      "sheets:spreadsheet",
      "wiki:wiki:readonly"
    ],
    "user": [
      "aily:file:read",
      "aily:file:write",
      "im:chat.access_event.bot_p2p_chat:read"
    ]
  }
}
```
豆包提供
```json
{
  "scopes": {
    "tenant": [
      "im:chat",
      "im:message:readonly",
      "im:message:send_as_bot",
      "contact:contact.base:readonly",
      "docs:document.content:read"
    ],
    "user": []
  }
}
```

导入后需在权限列表中为上述权限勾选并生效。

### 5. 启用机器人能力

在 **应用能力** → **机器人**：

1. 配置机器人名称（如「我的 AI 助手」）；
2. 开启机器人能力。

### 6. 配置事件订阅（需先完成 OpenClaw 侧配置）

**注意**：需先完成下方「三、在 OpenClaw 中添加飞书渠道」并**启动网关**，再配置事件订阅，否则长连接会保存失败。

在 **事件订阅** 页面：

1. 添加事件：`im.message.receive_v1`（接收消息）；
2. 选择 **使用长连接接收事件**（WebSocket 模式，无需公网域名）。

### 7. 发布应用

在 **版本管理与发布** 中创建版本并提交发布，企业自建应用一般由管理员审批后即可使用。

## 三、在 OpenClaw 中添加飞书渠道

### 方式一：交互式添加（推荐）

```bash
openclaw channels add
```

按提示选择 **Feishu**，输入飞书应用的 **App ID** 和 **App Secret** 即可。

### 方式二：编辑配置文件

编辑 `~/.openclaw/openclaw.json`（Windows 为 `%USERPROFILE%\.openclaw\openclaw.json`）：

```json
{
  "channels": {
    "feishu": {
      "enabled": true,
      "dmPolicy": "pairing",
      "accounts": {
        "main": {
          "appId": "cli_xxx",
          "appSecret": "你的AppSecret",
          "botName": "我的AI助手"
        }
      }
    }
  }
}
```

将 `cli_xxx` 和 `你的AppSecret` 替换为实际凭证。

### 方式三：环境变量

```bash
export FEISHU_APP_ID="cli_xxx"
export FEISHU_APP_SECRET="你的AppSecret"
```

---

## 四、启动网关并完成事件订阅

1. 确认网关已启动：
   ```bash
   openclaw gateway status
   ```
2. 若未启动，先启动网关，再回到飞书开放平台完成 **事件订阅** 中的「使用长连接接收事件」配置。
3. 若已修改配置，可重启网关使配置生效：
   ```bash
   openclaw gateway restart
   ```

---

## 五、私聊与群聊策略（可选）

- **私聊**：默认 `dmPolicy: "pairing"`，用户需先与机器人配对（如使用 `openclaw pairing approve feishu <配对码>` 批准）。
- **群聊**：默认需 @ 机器人才会回复；可在配置中设置 `groupPolicy`、`requireMention` 等，详见 [官方文档](https://openclawcn.com/docs/channels/feishu/)。

---

## 六、常用命令

| 命令 | 说明 |
|------|------|
| `openclaw gateway status` | 查看网关状态 |
| `openclaw gateway restart` | 重启网关 |
| `openclaw logs --follow` | 查看实时日志 |
| `openclaw pairing list feishu` | 查看飞书待审批配对 |
| `openclaw pairing approve feishu <配对码>` | 批准飞书用户配对 |

## 七、Lark 国际版

若使用 **Lark（国际版）**，在配置中增加 `domain: "lark"`，例如：

```json
{
  "channels": {
    "feishu": {
      "domain": "lark",
      "enabled": true,
      "accounts": {
        "main": {
          "appId": "cli_xxx",
          "appSecret": "xxx"
        }
      }
    }
  }
}
```

## 版本要求

- **Linux / macOS**：OpenClaw 2026.2.26 及以上  
- **Windows**：OpenClaw 2026.3.2 及以上  

查看版本：`openclaw -v`。

更多高级配置（多账号、群组策略、绑定不同 Agent 等）见 [飞书渠道官方文档](https://openclawcn.com/docs/channels/feishu/)。
