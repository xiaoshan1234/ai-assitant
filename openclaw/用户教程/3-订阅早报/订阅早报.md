# OpenClaw 计划任务：订阅每日科技早报

本文以 **每天定时推送科技新闻早报** 为例，说明如何在 OpenClaw 中设置计划任务（Cron Job）。计划任务由网关内置调度器执行，到点自动唤醒 AI 并可将结果推送到你已接入的聊天渠道（如 QQ、飞书、钉钉、Telegram 等）。

---

## 前置条件

- OpenClaw 已安装，**网关持续运行**（计划任务在网关进程内执行）。
- 已配置 **AI 模型**，并已接入 **至少一个聊天渠道**（用于接收早报推送）。
- 若希望 AI 能主动查新闻，建议启用 **网络搜索** 等技能（如 `web-search`），以便任务中执行“搜索并总结科技新闻”。

---

## 一、计划任务简要说明

- **定时任务**：按 cron 表达式或固定间隔在指定时间运行。
- **两种执行方式**：
  - **主会话（main）**：在主对话中排队一个“系统事件”，在下次心跳时执行，会沿用主会话上下文。
  - **独立会话（isolated）**：在专用 `cron:` 会话中跑一轮 AI，不占用主聊天记录，适合每日早报这类**独立、可推送**的任务。
- **推送方式**：独立任务可配置 `--announce`（摘要式推送）或 `--deliver`（完整输出推送）到指定渠道。
- **持久化**：任务保存在 `~/.openclaw/cron/jobs.json`，重启网关不会丢失。

早报场景推荐：**独立会话 + 定时 cron + 推送到指定渠道**。

---

## 二、添加「每日科技早报」计划任务

在终端执行（将下面的渠道与接收目标改成你自己的）：

```bash
openclaw cron add \
  --name "科技早报" \
  --cron "0 8 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "请搜索并总结今天国内外主要科技新闻，用简洁的列表形式列出 5～8 条，每条一句话。只输出早报内容，不要多余寒暄。" \
  --announce \
  --channel telegram \
  --to "你的Telegram聊天ID或群组ID"
```

**参数说明**：

| 参数 | 含义 | 本例 |
|------|------|------|
| `--name` | 任务名称，便于管理 | 科技早报 |
| `--cron` | 5 位 cron 表达式（分 时 日 月 周） | `0 8 * * *` = 每天 8:00 |
| `--tz` | 时区（IANA） | Asia/Shanghai（北京时间） |
| `--session isolated` | 在独立会话中执行，不污染主对话 | 必选 |
| `--message` | 发给 AI 的提示词 | 要求搜索并总结科技新闻 |
| `--announce` | 将 AI 的摘要推送到渠道 | 也可用 `--deliver` 推送完整输出 |
| `--channel` | 推送到的渠道 | 见下方「渠道与目标」 |
| `--to` | 该渠道下的具体接收目标 | 见下方 |

**cron 表达式示例**（均为北京时间 8 点为例，`--tz "Asia/Shanghai"`）：

- 每天 8:00：`0 8 * * *`
- 工作日 8:00：`0 8 * * 1-5`
- 每天 7:30：`30 7 * * *`

---

## 三、渠道与接收目标（--channel / --to）

根据你已接入的渠道替换 `--channel` 和 `--to`。若省略 `--channel` 和 `--to`，会推送到「上次对话的渠道」（last）。

| 渠道 | --channel | --to 示例 |
|------|-----------|-----------|
| QQ | qqbot | 机器人对应的用户/群 ID（具体格式以插件文档为准） |
| 飞书 | feishu | 用户或群 ID（见飞书开放平台） |
| 钉钉 | dingtalk | 会话 ID 或用户 ID（见钉钉文档） |
| 企业微信 | wecom | 用户或群 ID（见企微文档） |
| Telegram | telegram | 个人：你的 chat_id；群组：`-100xxxxxxxxxx`；主题：`-100xxxxxxxxxx:topic:123` |
| Slack | slack | `channel:C1234567890` 或 `user:U1234567890` |

**示例：推送到 QQ 机器人私聊**

若你的 QQ 渠道已配对，可先不写 `--to`，使用「上次对话」推送；或查阅所用 QQ 插件的目标格式后填写，例如：

```bash
openclaw cron add \
  --name "科技早报" \
  --cron "0 8 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "请搜索并总结今天国内外主要科技新闻，用简洁的列表形式列出 5～8 条，每条一句话。只输出早报内容，不要多余寒暄。" \
  --announce \
  --channel qqbot
```

**示例：推送到飞书**

```bash
openclaw cron add \
  --name "科技早报" \
  --cron "0 8 * * *" \
  --tz "Asia/Shanghai" \
  --session isolated \
  --message "请搜索并总结今天国内外主要科技新闻，用简洁的列表形式列出 5～8 条，每条一句话。只输出早报内容，不要多余寒暄。" \
  --announce \
  --channel feishu \
  --to "ou_xxxxxxxx"
```

具体 `--to` 的取值需参考各渠道的文档或 OpenClaw 该渠道的说明。

## 四、管理计划任务

| 命令 | 说明 |
|------|------|
| `openclaw cron list` | 列出所有计划任务 |
| `openclaw cron run <jobId> --force` | 立即执行指定任务（用于测试） |
| `openclaw cron runs --id <jobId> --limit 20` | 查看该任务最近运行记录 |
| `openclaw cron edit <jobId> --message "新提示词"` | 修改任务的提示词 |
| `openclaw cron edit <jobId> --enabled false` | 禁用任务（不删除） |

添加任务后，终端会输出该任务的 `jobId`，请记下以便后续 `edit` / `run` / `runs` 使用。

## 五、测试早报任务

1. 添加任务后执行：
   ```bash
   openclaw cron list
   ```
   记下「科技早报」对应的 `jobId`。

2. 手动触发一次，检查是否收到推送：
   ```bash
   openclaw cron run <jobId> --force
   ```

3. 在对应渠道（QQ/飞书/钉钉等）查看是否收到 AI 总结的早报内容。若未收到，可执行 `openclaw logs --follow` 查看网关日志排查。

## 六、可选：让早报更靠谱（技能与提示词）

- **网络搜索**：若已安装并启用 `web-search` 等技能，AI 在独立会话中也可调用，便于执行“搜索并总结今日科技新闻”。可在添加任务前执行：
  ```bash
  openclaw skills list
  openclaw skills install web-search   # 按实际技能名
  openclaw skills enable web-search
  ```
- **提示词**：可根据需要修改 `--message`，例如限定来源（“以中文科技媒体为主”）、条数、格式（Markdown 列表、带链接等）。

## 七、常见问题

| 现象 | 处理建议 |
|------|----------|
| 到点没有推送 | ① 确认网关一直在运行（`openclaw gateway status`）；② 确认任务已启用（`openclaw cron list` 中该任务无禁用）；③ 检查 `--tz` 与系统时区是否一致；④ 查看 `openclaw logs --follow` 是否有 cron 或渠道报错。 |
| 推送失败 / 收不到 | 检查 `--channel` 与 `--to` 是否与已接入渠道一致，格式是否符合该渠道要求；必要时先用 `openclaw cron run <jobId> --force` 看日志报错。 |
| 希望改时间或内容 | 使用 `openclaw cron edit <jobId> --cron "0 7 * * *"` 或 `--message "新提示"` 等修改后，无需重启网关。 |
