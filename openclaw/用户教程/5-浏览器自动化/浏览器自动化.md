# OpenClaw 浏览器自动化

本文介绍如何使用 OpenClaw 的**浏览器工具**进行网页自动化——让 AI 控制真实浏览器完成打开页面、点击、填表、截图等操作，适用于日常办公中的重复性网页任务（如打开内部系统、填报表单、截取页面等）。

---

## 一、浏览器自动化能做什么

- **打开网页**：按你或 AI 的指令访问指定 URL。
- **点击与输入**：点击按钮、链接，在输入框中填写文字。
- **截图与快照**：截取当前页面或指定区域，生成截图或 PDF。
- **等待与导航**：等待页面加载、网络空闲或某元素出现后再继续操作。
- **多标签页**：管理多个标签页（打开、切换、关闭）。

AI 通过「浏览器工具」在安全、隔离的环境里操作，不会直接动你日常使用的浏览器个人数据（在使用托管模式时）。

---

## 二、前置条件

- OpenClaw 已安装，**网关处于运行状态**（`openclaw gateway status` 为 running）。
- 已配置 **AI 模型**。
- **有图形界面**的电脑：若使用**本地托管浏览器**，需要能启动 Chromium；无图形界面（如纯服务器）时可使用**远程浏览器服务**（如 Browserless）。

---

## 三、两种使用方式

### 1. 通过对话让 AI 操作（推荐）

在已接入的渠道（QQ、飞书、钉钉、Telegram 等）或 Control UI 中，**用自然语言描述任务**，AI 会自动调用浏览器工具执行，例如：

- 「打开 https://example.com 并截一张首页截图」
- 「打开我们公司 OA 登录页，等我告诉你账号密码后再填」
- 「去 https://news.xxx.com 把今天头条标题和摘要抓给我」

无需手写脚本，只要描述清楚目标即可。

### 2. 使用 CLI 手动操作

在终端用 `openclaw browser` 命令直接控制浏览器（查看状态、打开 URL、截图等），适合调试或与脚本配合：

```bash
openclaw browser --browser-profile openclaw status
openclaw browser --browser-profile openclaw open https://example.com
openclaw browser --browser-profile openclaw snapshot
```

## 四、两种浏览器模式

OpenClaw 支持两种浏览器使用方式，对应不同「配置文件（profile）」：

| 模式 | profile | 说明 |
|------|---------|------|
| **OpenClaw 托管浏览器** | `openclaw` | 由 OpenClaw 启动的**独立 Chromium**，与你的个人浏览器完全隔离，Cookie/登录状态独立。无需安装浏览器扩展。 |
| **Chrome 扩展中继** | `chrome` | 控制你**本机已打开的 Chrome/Brave/Edge**，需安装 OpenClaw 浏览器扩展并附加到对应标签页。适合需要沿用本机已登录状态的场景。 |

多数办公自动化场景推荐使用 **`openclaw` 托管模式**，隔离且不干扰个人浏览。

## 五、启用并配置浏览器

### 1. 确认浏览器功能已启用

配置位于 `~/.openclaw/openclaw.json`（Windows：`%USERPROFILE%\.openclaw\openclaw.json`）。确保未禁用浏览器：

```json
{
  "browser": {
    "enabled": true,
    "defaultProfile": "openclaw"
  }
}
```

- `enabled: true`：启用浏览器工具（默认多为 true）。
- `defaultProfile`：`"openclaw"` 表示默认使用托管浏览器；`"chrome"` 表示默认使用扩展中继。

若之前未配置过 `browser`，只要没有在其他地方禁用它，通常可直接进行下一步。

### 2. 使用托管浏览器前（可选依赖）

托管模式会启动 Chromium。若系统尚未安装 Chromium，可安装 Playwright 提供的 Chromium：

```bash
npx playwright install chromium
```

Docker 或无头服务器环境可能还需安装系统依赖，请参考 [Playwright 文档](https://playwright.dev/docs/intro)。

### 3. 多配置与远程浏览器（可选）

可在 `browser.profiles` 下配置多个 profile，例如隔离「办公」与「个人」、或使用远程 CDP（如 Browserless）：

```json
{
  "browser": {
    "enabled": true,
    "defaultProfile": "openclaw",
    "profiles": {
      "openclaw": { "cdpPort": 18800, "color": "#FF4500" },
      "work": { "cdpPort": 18801, "color": "#0066CC" },
      "browserless": {
        "cdpUrl": "https://production-sfo.browserless.io?token=你的TOKEN",
        "color": "#00AA00"
      }
    }
  }
}
```

- 本地 profile（如 `openclaw`、`work`）可指定 `cdpPort` 区分实例。
- 远程 profile（如 `browserless`）使用 `cdpUrl` 连接云端浏览器，适合无 GUI 的服务器。

修改配置后需**重启网关**：`openclaw gateway restart`。

## 六、常用 CLI 命令

以下命令均可在前加 `--browser-profile <名称>` 指定使用的 profile（不写则用默认）。

| 命令 | 说明 |
|------|------|
| `openclaw browser status` | 查看当前浏览器状态（是否在运行、当前 URL 等） |
| `openclaw browser start` | 启动浏览器（托管模式） |
| `openclaw browser open <URL>` | 打开指定网址 |
| `openclaw browser snapshot` | 获取当前页面快照（供 AI 或后续步骤使用） |
| `openclaw browser screenshot [--output <路径>]` | 截取当前页面并可选保存到文件 |

示例（使用托管 profile）：

```bash
openclaw browser --browser-profile openclaw status
openclaw browser --browser-profile openclaw start
openclaw browser --browser-profile openclaw open https://example.com
openclaw browser --browser-profile openclaw snapshot
```

若提示 "Browser disabled"，请检查配置中 `browser.enabled` 是否为 `true` 并重启网关。

## 七、办公场景示例

### 1. 打开内部系统并截图

在聊天中对 AI 说：

- 「用浏览器打开 https://oa.公司.com 并截一张图发给我。」

AI 会调用浏览器工具打开该 URL 并截图（或生成快照），再通过当前渠道发给你。

### 2. 填表与点击

- 「打开 https://xxx.com/form，在「姓名」框里填张三，「部门」选技术部，然后点提交按钮。」

AI 会依次执行打开页面、定位输入框、选择下拉项、点击按钮等操作。若需登录，可先让 AI 打开登录页，你再提供账号密码（建议用测试账号或专用账号，见下方安全说明）。

### 3. 定时或按需抓取页面信息

结合 [计划任务](../3-计划与任务/订阅早报.md)，可让 AI 每天固定时间打开某新闻/报表页，提取关键信息并推送到飞书或钉钉。

## 八、安全与隔离

- **托管浏览器（openclaw profile）**：与系统里你日常用的浏览器**相互隔离**，Cookie、登录状态、历史记录独立，不会混用。
- **敏感账号**：尽量不要让 AI 在不可信或外部网站填写你的主账号密码；可为自动化单独申请**专用账号**或仅用于内网系统。
- **远程 CDP**：使用 Browserless 等云浏览器时，流量与页面内容会经过第三方，敏感内部系统建议只用本地或自建远程浏览器。

## 九、常见问题

| 现象 | 处理建议 |
|------|----------|
| 提示 "Browser disabled" | 在 `openclaw.json` 中设置 `browser.enabled: true`，并重启网关。 |
| 托管浏览器无法启动 | 执行 `npx playwright install chromium`；Linux 无 GUI 时考虑使用远程 Browserless 或 headless 配置。 |
| AI 不调用浏览器 | 确认配置里浏览器未被禁用；在对话中**明确说出「用浏览器打开…」「在浏览器里…」**等，便于 AI 选择浏览器工具。 |
| 想用本机已登录的 Chrome | 使用 `chrome` profile：安装 OpenClaw 浏览器扩展（`openclaw browser extension install`），在浏览器中打开要控制的页面并附加扩展，再将 defaultProfile 设为 `chrome`（或使用 `--browser-profile chrome`）。 |
