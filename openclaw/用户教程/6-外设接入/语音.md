# OpenClaw 语音接入：用语音操控 + 外放回答问题

本文介绍如何让 OpenClaw 支持**语音输入**（你说的话被识别并交给 AI）和**语音输出**（AI 的回复通过扬声器/外放读出来），实现「说一句 → AI 处理 → 用声音回答」的完整语音对话。

---

## 一、整体架构

OpenClaw 的语音能力由几部分组成，可单独或组合使用：

| 组件 | 作用 | 常用方案 | 大致成本 |
|------|------|----------|----------|
| **STT（语音转文字）** | 把你的话转成文字发给 AI | OpenAI Whisper API | 约 $0.006/分钟 |
| **TTS（文字转语音）** | 把 AI 的回复用声音读出来（外放） | ElevenLabs | 免费额度或约 $5～22/月 |
| **Talk 模式** | 连续的「听 → 处理 → 说」对话循环 | 内置 | 仅消耗上面两种 API |
| **语音唤醒（可选）** | 说唤醒词（如「Hey OpenClaw」）后开始听 | 内置 | 免费 |

- **语音操控** = 开启 Talk 模式 + 配置 STT（Whisper），用麦克风说话即可控制 OpenClaw。  
- **外放回答问题** = 配置 TTS（ElevenLabs），AI 的回复会通过**系统默认扬声器**播放。

---

## 二、前置条件

- OpenClaw 已安装，**网关在运行**（`openclaw gateway status` 为 running）。
- 已配置 **AI 模型**（用于理解并回复）。
- **麦克风**：用于语音输入（STT）。
- **扬声器/外放**：用于语音输出（TTS）；通常即系统默认播放设备，无需额外配置。
- **API 密钥**：  
  - **OpenAI API Key**：用于 Whisper 语音识别（若已有 GPT 等 OpenAI 模型配置，可复用）。  
  - **ElevenLabs API Key**：用于 TTS 语音合成；在 [elevenlabs.io](https://elevenlabs.io/) 注册后可获取，有免费额度。

---

## 三、语音识别（STT）：让 OpenClaw「听得见」你

使用 **OpenAI Whisper** 将你说的话转成文字，再交给 AI 处理。

### 1. 获取 OpenAI API Key

若尚未拥有：在 [OpenAI 平台](https://platform.openai.com/) 注册并创建 API Key。Whisper 按音频时长计费（约 $0.006/分钟）。

### 2. 配置 STT

在 OpenClaw 配置中启用 Whisper。配置文件位置：

- **Windows**：`%USERPROFILE%\.openclaw\openclaw.json`
- **Linux / macOS**：`~/.openclaw\openclaw.json`

添加或合并 `stt` 配置（具体键名以你使用的 OpenClaw 版本为准，常见形式如下）：

```json
{
  "stt": {
    "provider": "whisper",
    "api_key": "${OPENAI_API_KEY}",
    "model": "whisper-1",
    "language": "zh"
  }
}
```

- `language`：可设为 `zh`（中文）或 `en`（英文）；不填则自动检测。
- 推荐通过环境变量传入密钥：在系统或 `~/.openclaw/.env` 中设置 `OPENAI_API_KEY=sk-xxx`，配置里用 `"${OPENAI_API_KEY}"` 引用。

部分版本可能将 STT 放在 `voice` 或其它节点下，请以官方文档为准。

---

## 四、语音合成（TTS）：让 OpenClaw「说出口」并用外放播放

使用 **ElevenLabs** 将 AI 的回复转成语音，通过**系统默认扬声器（外放）**播放。

### 1. 获取 ElevenLabs API Key 与语音 ID

1. 在 [elevenlabs.io](https://elevenlabs.io/) 注册并登录。  
2. 在个人设置或 API 页面复制 **API Key**。  
3. 在「Voices」中选一个声音，复制其 **Voice ID**（如 Rachel: `21m00Tcm4TlvDq8ikWAM`）。

免费档有每月字符数限制，适合先试；长期使用可考虑付费方案。

### 2. 配置 TTS（Talk 模式用）

Talk 模式下，回复会通过 TTS 读出来。在 `openclaw.json` 中配置 **talk**（或你版本中的 TTS 节点），例如：

```json
{
  "talk": {
    "apiKey": "${ELEVENLABS_API_KEY}",
    "voiceId": "21m00Tcm4TlvDq8ikWAM",
    "modelId": "eleven_multilingual_v2",
    "interruptOnSpeech": true
  }
}
```

- **apiKey**：ElevenLabs API Key，建议用环境变量 `ELEVENLABS_API_KEY`。  
- **voiceId**：上面复制的 Voice ID；中文可用多语言模型 + 中文 Voice。  
- **modelId**：如 `eleven_multilingual_v2`（多语言）、`eleven_v3` 等，以 ElevenLabs 文档为准。  
- **interruptOnSpeech**：`true` 时，你在 AI 朗读过程中说话会打断播放并开始听你的新输入。

若版本支持 `talk.tts` 多提供商格式，可能形如：

```json
{
  "talk": {
    "tts": {
      "provider": "elevenlabs",
      "elevenlabs": {
        "api_key": "${ELEVENLABS_API_KEY}",
        "voice_id": "你的Voice_ID",
        "model": "eleven_multilingual_v2"
      }
    }
  }
}
```

环境变量示例（与上面二选一或同时存在）：

```bash
export ELEVENLABS_API_KEY=你的ElevenLabs密钥
export ELEVENLABS_VOICE_ID=你的Voice_ID
```

### 3. 外放设备说明

- TTS 输出的音频会交给**系统默认播放设备**播放，即你电脑/设备当前选中的**扬声器或耳机**。  
- 无需在 OpenClaw 里单独配置「外放设备」：在系统设置中把需要的扬声器设为默认即可。  
- 若听不到声音：检查系统音量、是否静音、是否选错了输出设备；再查网关日志是否有 TTS 报错。

## 五、启用 Talk 模式（语音操控 + 外放回答）

Talk 模式 = 持续循环：**听你说话（STT）→ 发给 AI 处理 → 用 TTS 朗读回复（外放）**。

### 1. 确认启用

在配置中确保 Talk/语音相关功能已开启，例如（键名以你版本为准）：

```json
{
  "voice": {
    "talk_mode": {
      "enabled": true,
      "auto_detect_silence": true,
      "silence_threshold_ms": 1500,
      "continuous": true
    }
  }
}
```

- **continuous: true**：一次激活后持续处于对话状态，无需每次重新点开。  
- **silence_threshold_ms**：静音多少毫秒后认为你说完了（如 1500 = 1.5 秒），可避免还没说完就被截断。  
- **auto_detect_silence**：是否自动检测静音结束；否则可能需要手动按键结束说话。

若你使用的版本用 `talk.enabled` 等单一开关，以官方文档为准。

### 2. 重启网关

修改配置后执行：

```bash
openclaw gateway restart
```

### 3. 如何开始「语音操控」

- **网页控制端**：打开 OpenClaw 控制页（如 `http://127.0.0.1:18789`），在对话界面点击 **麦克风图标** 进入 Talk 模式，然后对着麦克风说话即可。  
- **语音唤醒（若已开启）**：说出配置的唤醒词（如 "Hey OpenClaw"），再直接说话。  
- **通过渠道**：在 QQ/飞书/钉钉等发送「打开语音模式」「开始对话」等，若 SOUL.md 或 agent 配置了对应指令，也可间接进入语音流程（具体取决于渠道与实现）。

说完后，系统会根据静音检测或结束操作把语音转成文字发给 AI，AI 的回复会通过 **TTS 用外放读出来**。

## 六、可选：语音唤醒（免提唤醒）

若希望「说一句话就唤醒，不用点鼠标」：

在配置中启用 wake，例如：

```json
{
  "voice": {
    "wake": {
      "enabled": true,
      "wake_word": "hey openclaw",
      "sensitivity": 0.5,
      "cooldown_seconds": 2
    }
  }
}
```

- **wake_word**：唤醒词，可改成你喜欢且不易误触发的短语。  
- **sensitivity**：灵敏度，过高易误唤醒，过低可能难唤醒。  
- **cooldown_seconds**：两次唤醒之间的最小间隔。

唤醒词检测一般在**本机**处理，不会把持续录音上传；只有检测到唤醒后，后续语音才会送给 Whisper。若介意常驻麦克风，可关闭 wake，仅用界面按钮进入 Talk 模式。

---

## 七、可选：sag 技能（ElevenLabs 朗读）

除了 Talk 模式自动朗读回复，还可以通过 **sag** 技能让 AI 主动「用指定声音读一段内容」（同样走系统外放）：

1. 安装 sag（若使用 ClawHub）：  
   `clawhub install sag` 或按官方文档安装 openclaw/skills 中的 sag。  
2. 配置 ElevenLabs：设置 `ELEVENLABS_API_KEY`（及可选 `ELEVENLABS_VOICE_ID`）。  
3. 在对话中让 AI「用语音读出来」或调用 sag，即可通过外放听到朗读。

## 八、常见问题

| 现象 | 处理建议 |
|------|----------|
| 听不见我说话 / 没反应 | 确认 Talk 模式已激活（麦克风图标或唤醒成功）；检查麦克风权限与系统默认录音设备；查看网关日志中 STT 相关报错（如 `grep -i stt`）。 |
| 没有外放声音 | 确认 TTS 已配置且 `apiKey`/`voiceId` 正确；检查系统音量与默认播放设备；日志中搜索 TTS/elevenlabs 报错。 |
| 说一半就被截断 | 增大 `silence_threshold_ms`（如 2000～3000）；确认 `auto_detect_silence` 已开启。 |
| 语音唤醒不灵 | 调高 `sensitivity` 或换一个更清晰、不易与日常用语混淆的唤醒词；确认麦克风权限与设备正常。 |
| 想用中文 | STT 中设置 `language: "zh"`；TTS 使用支持多语言的模型（如 `eleven_multilingual_v2`）并选合适 Voice ID。 |

**小结**：要**用语音操控 OpenClaw**，需配置 **STT（Whisper）** 并启用 **Talk 模式**；要**用外放听 AI 回答**，需配置 **TTS（ElevenLabs）**。外放即系统默认扬声器，无需在 OpenClaw 里单独选设备。配置完成后重启网关，在网页点麦克风或说唤醒词即可开始语音对话。
