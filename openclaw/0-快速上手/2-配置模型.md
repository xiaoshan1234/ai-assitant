# OpenClaw 配置 Qwen 3.5 Plus 模型

本文介绍如何在 OpenClaw 中接入 **Qwen 3.5 Plus**（通义千问 3.5 Plus），使用阿里云百炼（DashScope）的 OpenAI 兼容 API。

---

## 一、获取 API Key（阿里云百炼）

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)（原 DashScope），使用阿里云账号登录。
2. 进入 **API-KEY 管理**（或「密钥管理」），点击 **创建 API-KEY**。
3. 复制生成的 Key（格式一般为 `sk-xxx`），**仅展示一次，请妥善保存**。
4. 新用户可在控制台领取免费额度，按量计费后需保证账户有余额方可继续调用。

---

## 二、在 OpenClaw 中配置 Qwen 3.5 Plus

Qwen 3.5 Plus 通过 **OpenAI 兼容接口** 提供，在 OpenClaw 中按「自定义模型提供商」方式配置即可。

### 方式一：编辑配置文件（推荐）

1. 打开 OpenClaw 主配置：
   - **Windows**：`%USERPROFILE%\.openclaw\openclaw.json`
   - **Linux / macOS**：`~/.openclaw/openclaw.json`

2. 在 `models.providers` 中增加 `dashscope` 提供商，并设置默认模型，例如：

```json
{
  "models": {
    "mode": "merge",
    "providers": {
      "dashscope": {
        "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
        "apiKey": "${DASHSCOPE_API_KEY}",
        "api": "openai-completions",
        "models": [
          {
            "id": "qwen3.5-plus",
            "name": "Qwen 3.5 Plus",
            "reasoning": false,
            "input": ["text", "image"],
            "contextWindow": 128000,
            "maxTokens": 8192
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": { "primary": "dashscope/qwen3.5-plus" }
    }
  }
}
```

3. 配置 API Key（二选一）：
   - **环境变量（推荐）**：在系统或 `~/.openclaw/.env` 中设置：
     ```bash
     DASHSCOPE_API_KEY=sk-你的API密钥
     ```
   - **直接写在配置里**：将 `"apiKey": "${DASHSCOPE_API_KEY}"` 改为 `"apiKey": "sk-你的API密钥"`（不推荐，易泄露）。

4. 若已有其他 `models` 或 `agents` 配置，只需把上面的 `providers.dashscope` 和 `agents.defaults.model` 合并进现有配置即可，保持 `mode: "merge"`。

### 方式二：使用配置向导（若支持）

部分版本支持通过向导选择模型与网关：

```bash
openclaw configure --section model
```

或首次安装时：

```bash
openclaw onboard
```

若向导中有「OpenAI 兼容」或「自定义 URL」选项，可填写：

- **Base URL**：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- **API Key**：你的百炼 API Key  
- **模型 ID**：`qwen3.5-plus`

完成后同样需在配置中确认 `agents.defaults.model.primary` 为 `dashscope/qwen3.5-plus`（或你自定义的 provider 名/模型 id）。

---

## 三、不同地域的接入地址（可选）

阿里云百炼提供多地域 OpenAI 兼容端点，可按需替换 `baseUrl`：

| 地域         | baseUrl |
|--------------|---------|
| 中国内地     | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 新加坡（国际） | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` |
| 美国（弗吉尼亚） | `https://dashscope-us.aliyuncs.com/compatible-mode/v1` |

国内用户一般使用第一个即可。

---

## 四、生效与验证

1. **重启网关**使配置生效：
   ```bash
   openclaw gateway restart
   ```

2. **检查配置与模型列表**：
   ```bash
   openclaw doctor
   openclaw models list
   ```
   在列表中应能看到 `dashscope/qwen3.5-plus`（或你配置的 ID）。

3. **指定当前使用模型**（若未在 `agents.defaults.model` 中写死）：
   ```bash
   openclaw models set dashscope/qwen3.5-plus
   ```

4. 在 OpenClaw 的聊天渠道中发一条消息，能正常回复即表示 Qwen 3.5 Plus 已接入成功。

---

## 五、其他 Qwen 模型（可选）

- **快照/指定版本**：部分地域支持带日期的模型 ID，如 `qwen3.5-plus-2026-02-15`，可在百炼文档中查看当前可用 ID，并在 `models.providers.dashscope.models` 中增加一项，`id` 填该名称即可。
- **免费额度（Qwen Portal OAuth）**：若仅需体验、不需要 3.5 Plus，可使用官方 Qwen Portal 免费模型（每日限额）：
  ```bash
  openclaw plugins enable qwen-portal-auth
  openclaw models auth login --provider qwen-portal --set-default
  ```
  可用模型包括 `qwen-portal/vision-model`、`qwen-portal/coder-model` 等，与百炼 API Key 方式二选一或并存（通过 `openclaw models set` 切换）。

---

## 六、常见问题

| 现象 | 处理建议 |
|------|----------|
| 网关启动报错或模型列表为空 | 检查 `openclaw.json` 中 `baseUrl` 是否以 `/v1` 结尾，`api` 是否为 `openai-completions`，以及 API Key 是否有效。 |
| 调用报 401/403 | 确认百炼 API Key 正确、未过期，且账号有额度或已开通按量计费。 |
| 工具调用/Function Calling 异常 | Qwen 3.5 Plus 支持工具调用；若仍有问题，可尝试在对应模型配置中设置 `params: { "streaming": false }` 或查阅 OpenClaw 与百炼文档。 |

配置完成后，OpenClaw 的默认对话将使用 **Qwen 3.5 Plus**；如需切换回其他模型，使用 `openclaw models set <provider/model-id>` 或修改 `agents.defaults.model.primary` 即可。
