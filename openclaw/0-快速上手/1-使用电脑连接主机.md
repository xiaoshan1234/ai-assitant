# 1. 前置条件
1. 盒子已经连接到路由器，网口灯闪烁   
2. 手机/电脑 与盒子连接到一个路由器

# 2. 电脑连接
## 2.1. 准备终端工具
1. 搜索 cmd
点击微软开始菜单，搜索cmd，点击命令提示符

## 2.2. 测试盒子连通性
输入下面的命令测试盒子联通性(openclaw是盒子的默认设备名称，后续可自行更改)

    ping openclaw -4

![](https://raw.githubusercontent.com/xiaoshan1234/picture/master/res/2026-05-11-20-31-bd584f6fb25c22e38c73902f0c320751.png)  
正常的回应如上图所示，记住 ip 地址

## 2.3. ssh连接
输入命令进行登录（ssh xxx@yyy | xxx是用户名，yyy是设备名或者ip地址）  
    
    ssh openclaw@openclaw
然后输入密码，注意！输入密码不会有任何显示，输完以后直接回车就行
    
    1qaz@WSX

![](https://raw.githubusercontent.com/xiaoshan1234/picture/master/res/2026-05-11-20-31-d8c5506706e8c4c04053e88f81673d97.png)

## 2.6. 文件访问
在路径栏输入(主机名)  

    \\openclaw
![](https://raw.githubusercontent.com/xiaoshan1234/picture/master/res/2026-05-11-20-31-8835b653edcb6e073b1a112508013115.png)

会有登录提示，输入用户名与密码（同ssh） 
    
    username: openclaw
    password: 1qaz@WSX

成功后显示如下文件夹

![](https://raw.githubusercontent.com/xiaoshan1234/picture/master/res/2026-05-11-20-31-16c8af5c3865c327c6c3e7a369471d49.png)

这两个文件夹本质是一样的，是openclaw用户的家目录，相当于一个人的名字与外号，进入这两个文件夹，主要有下面的文件与文件夹

![](https://raw.githubusercontent.com/xiaoshan1234/picture/master/res/2026-05-11-20-32-69f9ff5c31f40b000f949f859bd89db7.png)
![](https://raw.githubusercontent.com/xiaoshan1234/picture/master/res/2026-05-11-20-32-53a4dc3e4bb3ec3eefe3f5ad73f2add4.png)

下面的文件夹是openclaw助手的主要工作区，openclaw助手生成的脚本，图片，视频等一般都在这里

    .openclaw\workspace

下面这个文件是openclaw的配置文件，想要对openclaw进行精细的控制，需要修改此文件，目前先不用关心

    .openclaw\workspace\openclaw.json
