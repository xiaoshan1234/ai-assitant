## 安装 openclaw
```sh
# 依赖
sudo apt install -y curl git ca-certificates gnupg lsb-release polkitd pkexec
# 代理

# 脚本
curl -fsSL https://openclaw.ai/install.sh | bash

# 推荐非root用户安装

# 初始化
openclaw onboard --install-daemon

# 配置
xs@openclaw:~$ mkdir -p ~/.config/systemd/user/
xs@openclaw:~$ touch ~/.config/systemd/user/openclaw-gateway.service
xs@openclaw:~$ vim ~/.config/systemd/user/openclaw-gateway.service

# service
[Unit]
Description=OpenClaw Gateway
After=network-online.target
Wants=network-online.target

[Service]
ExecStart=/home/xs/.npm-global/bin/openclaw gateway --port 18789
Restart=always
RestartSec=5

[Install]
WantedBy=default.target

# 服务加载
systemctl --user daemon-reload 
systemctl --user enable openclaw-gateway 

# 远程访问

# 配置文件
/home/openclaw/.openclaw/config.yaml
```

## openclaw 卸载

官方文档：<https://docs.openclaw.ai/install/uninstall>

若本机还能执行 `openclaw`（推荐）：

```sh
# 一行非交互（适合脚本；会按官方说明停服务、清数据、卸 CLI 等，以你本机 help 为准）
openclaw uninstall --all --yes --non-interactive
# 或
npx -y openclaw uninstall --all --yes --non-interactive
```

分步与「与上面等效」的手动做法：

```sh
openclaw gateway stop
openclaw gateway uninstall
rm -rf "${OPENCLAW_STATE_DIR:-$HOME/.openclaw}"   # 状态与配置
# 若配过自定义 OPENCLAW_CONFIG_PATH，需单独删该文件
# 可选：工作区（代理文件等）
rm -rf ~/.openclaw/workspace
npm rm -g openclaw   # 或用 pnpm remove -g / bun remove -g，视当初安装方式
```

通过 `curl https://openclaw.ai/install.sh | bash` 安装的，CLI 一般为全局 npm，可用 `npm rm -g openclaw`。

若 **CLI 已删但网关仍在跑**（Linux systemd 用户单元，与你上文自建 `openclaw-gateway.service` 一致）：

```sh
systemctl --user disable --now openclaw-gateway.service
rm -f ~/.config/systemd/user/openclaw-gateway.service
systemctl --user daemon-reload
```

说明：卸载不会自动撤销你在 Telegram/Slack/GitHub 等处的 OAuth 或 API 权限，需要到各平台自行撤销或轮换密钥。
